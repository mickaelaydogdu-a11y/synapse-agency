# SYNAPSE AGENCY — PLAN DE REFONTE DU SITE WEB

## 1. Contexte du projet

Synapse Agency dispose actuellement d’un site internet présentant plusieurs pôles de compétences :

* Intelligence artificielle
* Développement d’applications web/mobile
* Production visuelle

L’objectif de cette refonte est de simplifier le positionnement de l’entreprise et de recentrer Synapse Agency autour de deux expertises principales :

1. **Applications métier sur mesure**
2. **Intelligence artificielle & automatisation**

La production photo, vidéo et drone ne doit plus être considérée comme une activité centrale de Synapse Agency.

Elle pourra être conservée dans une page secondaire accessible depuis le footer, ou progressivement migrée vers une marque / activité distincte de type :

> Synapse Studio

---

# 2. Objectif stratégique

Synapse Agency ne doit plus être perçue comme une agence digitale généraliste.

Le nouveau positionnement doit être :

> **Synapse Agency conçoit des applications métier intelligentes intégrant l’intelligence artificielle et l’automatisation.**

La promesse principale est :

> **Nous transformons les processus de votre entreprise en applications intelligentes.**

L’objectif est de vendre non pas une technologie, mais une transformation opérationnelle.

Le site doit montrer que Synapse Agency est capable de :

* comprendre un processus métier ;
* identifier les tâches répétitives ;
* centraliser les données ;
* créer une application métier ;
* connecter les logiciels existants ;
* intégrer de l’intelligence artificielle ;
* automatiser certains processus ;
* exploiter les données de l’entreprise ;
* améliorer la productivité des collaborateurs.
